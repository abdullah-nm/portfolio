Prompt إنشاء النسخة B
Act as a professional portfolio designer and frontend developer. Build the first complete version of my personal portfolio website using the project context and the project files I provide. Create clear sections for my introduction, education, skills and interests, and Aqarak project. Describe the project’s purpose, my contribution, and the tools or techniques I used, using only the verified details provided. Make the content easy for a recruiter to scan and understand. Create a distinctive but professional visual identity suitable for an Information Systems student interested in AI and data. Use clean layouts, readable typography, a consistent color palette, and responsive behavior across mobile, tablet, and desktop. Include simple, useful navigation and working links. Do not invent missing information. Do not expose private contact details. If a detail would improve the portfolio but is missing, leave a clear placeholder or ask me instead of guessing. Build a functioning website, not a static design mockup. When finished, summarize the sections and features you implemented and list any information you still need from me.

Review the current portfolio in [PROJECT FILES OR CODE] as if you are a recruiter seeing it for the first time. Without relying on explanations from me, check whether a visitor can quickly: 1. Understand who I am and what I study. 2. Find my listed skills and interests. 3. Understand the purpose of Aqarak and what I contributed. 4. Navigate the site and open the LinkedIn link. 5. Use the portfolio comfortably on mobile and desktop. Inspect the visible content for unsupported claims, confusing wording, spelling issues, private contact information, broken links, and unfinished placeholders. Check the main navigation and interactive elements. Review basic accessibility, including keyboard navigation, heading structure, link clarity, color contrast, and reduced-motion behavior. Report findings by priority, explain the effect on a recruiter, and suggest a concrete fix for each issue.
